# Kamrun Nahar - Premium Portfolio Website

A modern, premium portfolio website built with React, Vite, and Tailwind CSS. Showcasing competitive programming, projects, achievements, and career aspirations.

## 🚀 Features

- **Premium Design**: Dark-first, sophisticated UI with accent colors and smooth animations
- **Fully Responsive**: Mobile-first design that works beautifully on all devices
- **Performance Optimized**: Fast loading with Vite, lazy loading, and code splitting
- **Accessible**: WCAG compliant with keyboard navigation and screen reader support
- **SEO Ready**: Proper meta tags, Open Graph, and semantic HTML
- **Smooth Animations**: Subtle transitions powered by Framer Motion
- **Dark/Light Mode**: Theme toggle with persistent storage
- **Modular Architecture**: Easy to maintain and update components

## 📋 Sections

1. **Hero** - Welcome with status and CTA buttons
2. **About** - Personal introduction and highlights
3. **Education** - Academic timeline (University, HSC, SSC)

## 📦 Installation

### Prerequisites
- Node.js (v16+)
- npm or yarn

### Setup

1. Clone or navigate to the project directory:
```bash
cd kamrun-nahar-portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Start development server:
```bash
npm run dev
```

The site will open at `http://localhost:3000`

## 🎨 Customization

### Personal Data
Update your personal information in `src/data/portfolioData.js`:
- Name, email, social links
- Education details
- Skills and technologies
- Projects information
- Achievements
- Experience
- And more...

### Colors & Styling
Customize the theme in `tailwind.config.js`:
- Accent colors
- Font families
- Animation timing
- Custom utilities

### Resume
Place your resume PDF at:
```
public/resume/Kamrun_Nahar_Resume.pdf
```

Update the path in `portfolioData.js` if needed.
